# Sky Tools

English | [繁體中文](./README.md)

A small collection of tools for **Sky: Children of the Light** players: a season spirit unlock calculator, a friend tree planner, and a height calculator. Everything is a static web page, and your progress stays in your own browser.

[Website](https://kevinvoid3.github.io/skytrust) | [GitHub repository](https://github.com/kevinvoid3/skytrust)

## ✨ Features

### 🕯️ Season Spirit Calculator (`spirit.html`)

- **Complete spirit trees**: season spirits, guides, regular spirits and elders, grouped by season and realm, laid out the way the game shows them
- **Progress tracking**: click an item to mark it unlocked; season candles required and spent, plus current affection and level, are calculated automatically
- **Affection thresholds**: each tier shows the affection needed to reach it, and a segmented bar on the left shows which tier you are in
- **Days remaining**: estimated from your daily candle income and starting candles
- **Season Pass marker**: Pass-only items carry a season pendant badge in the top-left corner of the icon
- **Hide graduation gifts and season pendants**: remembered per season; hidden items are left out of the totals
- **Cross-group search**: type an item, spirit or season name to jump to that cell and highlight it
- **Share links**: pack the current group's progress into a URL; the recipient sees a read-only view and can choose to apply it
- **Single-file offline version** (💾 Offline): the data is embedded in one HTML file you can open by double-clicking, no network needed
- **Multiple profiles**: keep separate progress for different characters, with export / import for backups
- **Compact mode**: on by default on phones, cells about 30% shorter

### 🤝 Friend Tree Planner (`friend.html`)

- Track several friends, each with their own unlock record
- Set a target level to see the candles and affection threshold needed, checked against your candle stock
- Full-unlock preview, reset, export / import

### 👤 Height Calculator (`height.html`)

- Upload, drag in or paste a screenshot of your outfit QR code, or paste the Base64 string or share link directly
- Shows your current height and the tallest and shortest this account can be
- The QR code is decoded in your browser; the image is never uploaded

### Shared across pages

- **Three languages**: Traditional Chinese / Simplified Chinese / English, one language setting for every page
- **Dark / light theme**: one theme setting for every page
- **Fully static**: no backend; works on GitHub Pages or any static host

## 📄 Data Files

The three `spirits.*.json` files are generated from game data by a build script in a separate private repository. **Do not edit them here** — the next update overwrites them entirely. If a translation or image is wrong, please open an issue.

**spirits.data.json**: each spirit's tree, grouped

```json
{
  "_meta": { "build": "2026-11-17a", "generated": "2026-11-19T11:09:06+08:00" },
  "season_32": {
    "spirits": {
      "questap32": {
        "kind": "guide",
        "tier": 4,
        "tiers": { "2": 400, "3": 800, "4": 1200 },
        "items": [
          { "k": "quest", "cst": 0, "ctyp": "season_candle", "exp": 200,
            "level": 1, "pass": false, "src": "quest_ap32_fetch_01" }
        ]
      }
    }
  }
}
```

| Field | Description |
|-------|-------------|
| Top-level keys | Groups: `season_N` (season), `elders`, `realm_*` (regular spirits by realm) |
| `kind` | `guide` = guide (2-D grid layout), `tree` = regular spirit tree |
| `tier` / `tiers` | Highest reachable level / cumulative affection required for each level |
| `k` | Item category; the display name is looked up in `spirits.i18n.json` |
| `cst` / `ctyp` | Price and currency (season candles, hearts, season hearts, …) |
| `exp` | Affection granted when unlocked |
| `level` | The level the item sits on |
| `pass` | Whether the item is Season Pass only |
| `src` | The game's item code; also the key for images and saved progress |

**spirits.i18n.json**: `{ "zh-hant": {…}, "zh": {…}, "en": {…} }`, keyed by group, spirit code and item category.

**spirits.images.json**: `{ item code: image URL }`. Images come from [skyinfoweb](https://skyinfoweb.pages.dev).

**friend_tree.json**: the data behind the Friend Tree Planner (`friend.html`). It defines every level of every friendship action on the friend tree: which tier it sits on, how many candles it costs and which icon it uses. There is one copy per language with the same structure; only `nm` (the display name) differs.

```json
{
  "zh-hant": {
    "FriendTree": {
      "items": [
        { "actionId": "duetbow", "nm": "雙人鞠躬", "level": 2, "tier": 3,
          "order": 8, "cst": 5, "exp": "10", "image": "https://skyinfoweb.pages.dev/image/…" }
      ]
    }
  },
  "zh": { "FriendTree": { "items": [ … ] } },
  "en": { "FriendTree": { "items": [ … ] } }
}
```

| Field | Description |
|-------|-------------|
| `actionId` | Friendship action code, shared by every level of the same action |
| `nm` | Display name (per language) |
| `level` | Which level of the action this is (1–4); the previous level must be unlocked first |
| `tier` | Which tier of the friend tree it sits on (1–7), which sets the affection needed to unlock it. Tier thresholds live in `TIER_REQ_EXP` in `friend.html` |
| `order` | Left-to-right order within the tier |
| `cst` | Candles needed to unlock |
| `exp` | Affection value; not currently used by the page |
| `image` | Icon URL, always from [skyinfoweb](https://skyinfoweb.pages.dev) |

> Progress is identified by `actionId` + `level`. Changing either field breaks the ticks players have already saved, so keep them stable when adding or adjusting items.

## 🚀 Deployment

1. Deploy the whole folder to a static host (GitHub Pages, Cloudflare Pages, etc.)
2. The pages load `data/` with `fetch`, so **opening the HTML files by double-clicking will not work**. To preview locally, run this in the folder:
   ```bash
   python -m http.server 8000
   ```
   then open `http://localhost:8000/`
3. For offline use on your own machine, press "💾 Offline" in the calculator to get a single HTML file

## 🔒 Privacy

- All progress, profiles and settings are stored only in your browser's `localStorage` and are never uploaded
- Share links keep the progress after the `#` in the URL, a part that is never sent to the server
- Clearing browser data clears your progress too — export a backup before switching devices or reinstalling
